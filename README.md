# Проєкт для завантаження та перегляду зображень

Це веб-додаток на Python, який дозволяє завантажувати зображення через браузер, зберігати їх у папці `images` і переглядати на окремій сторінці. Для розгортання використовується Docker Compose з NGINX як reverse proxy і веб-сервером Python для обробки запитів.

## Функціонал

- завантаження файлів через форму на головній сторінці;
- підтримувані формати: JPG, PNG, GIF;
- обмеження розміру файла: до 5 МБ;
- збереження файлів у каталозі `images/`;
- перегляд списку завантажених зображень на сторінці `http://localhost:8080/images`;
- віддача статичних файлів через NGINX;
- логування операцій у файл `logs/app.log`.

## Технології

- Python 3.10
- стандартна бібліотека `http.server`
- NGINX
- Docker / Docker Compose

## Архітектура

Проєкт складається з двох сервісів:

1. `app` — Python HTTP-сервер, який:
   - обробляє GET/POST запити;
   - приймає файли від клієнта;
   - створює унікальні імена файлів;
   - зберігає зображення в `images/`;
   - віддає сторінки та файли.

2. `nginx` — web-сервер, який:
   - приймає запити на порт 8080;
   - проксірує запити до Python-сервера на порту 8000;
   - обслуговує статичні ресурси з папки `static/`.

## Структура проєкту

```text
.
├── app.py                 # Основний Python-сервер
├── Dockerfile             # Docker-образ для Python-додатку
├── docker-compose.yml     # Конфігурація контейнерів
├── nginx.conf             # NGINX-конфігурація
├── requirements.txt       # Залежності Python
├── images/                # Збережені завантажені зображення
├── logs/                  # Логи додатку
├── static/
│   ├── index.html         # Головна сторінка з формою завантаження
│   ├── images.html        # Сторінка зі списком зображень
│   └── style.css          # CSS-стилі
└── README.md              # Документація проєкту
```

## Передумови

Для запуску проєкту потрібні:

- Docker
- Docker Compose

## Запуск проєкту

1. Перейдіть до каталогу проєкту:

2. Запустіть збірку та контейнери:

```bash
docker-compose up -d --build
```

3. Відкрийте браузер і перейдіть за адресою:

```text
http://localhost:8000
```

Після запуску доступні такі маршрути:

- `/` — головна сторінка для завантаження файлів;
- `/images` — сторінка зі списком зображень;
- `/images/<filename>` — відкриття конкретного зображення;
- `/static/...` — статичні ресурси.

## Зупинка проєкту

```bash
docker-compose down
```

Якщо потрібно зупинити контейнери з видаленням томів, можна використати:

```bash
docker-compose down -v
```

## Логи

Логи Python-додатку зберігаються у файлі:

```text
logs/app.log
```

## Налаштування середовища

У `docker-compose.yml` задано змінну середовища:

```yaml
environment:
  - LOG_DIR=/logs
```

Це означає, що логи Python-сервера будуть записуватись у каталог `/logs` в контейнері, який прокинуто до хостового каталогу `./logs`.

## Обмеження і правила роботи

- дозволені типи файлів: `jpg`, `png`, `gif`;
- максимальний розмір файлу — 5 МБ;
- файли зберігаються з випадковим унікальним іменем, щоб уникнути конфліктів;
- пошкоджені або недійсні запити повертають HTTP 400/404 відповідно.

## Розробка та зміни

Для локальних змін у коді достатньо редагувати файли `app.py`, `static/*.html`, `static/style.css` і перезапустити контейнери:

```bash
docker-compose restart app
```

Або повністю перезапустити сервіс:

```bash
docker-compose up -d --build
```
